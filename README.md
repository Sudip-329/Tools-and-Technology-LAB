# Tools-and-Technology-LAB — Python Programming

This repository contains all the **lab assignments and practice code** for the **Tools and Technology Lab** course.  

The primary focus of these labs is **Python programming**, covering concepts from **fundamental syntax to more advanced topics**, enabling learners to practice and strengthen their coding skills.

---

## 🎯 Purpose

- Learn and practice **Python programming basics**  
- Explore **data types, loops, functions, and file handling**  
- Solve **lab exercises and practical programming assignments**  

---

## 📂 Topics Covered

- **Python Basics:** Variables, Data Types, Operators, Loops, Conditional Statements  
- **Functions & Modules:** User-defined functions, Python modules, Lambda functions  
- **Data Structures:** Lists, Tuples, Dictionaries, Sets  
- **File Handling:** Reading/writing files, manipulating text data  
- **Advanced Concepts:** OOP in Python, Exception Handling, Python Libraries  
- **Practical Exercises:** Lab assignments from course sessions
